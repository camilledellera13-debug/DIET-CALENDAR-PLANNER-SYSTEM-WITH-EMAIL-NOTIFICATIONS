Diet Calendar Planner System with Email Notifications

Description

A web-based diet calendar planner system that helps users schedule meals, track nutrition, and receive email notifications for upcoming meals and diet plans.

Objectives

To help users plan and maintain a consistent diet routine
To provide a calendar-based meal planning system
To track daily nutritional intake and food expenses
To send automated email reminders for scheduled meals
To calculate total calories, nutrients, and remaining targets

Features

Create, edit, and delete meal plans
View diet schedules in a calendar interface
Set daily or weekly nutrition goals (calories, protein, carbs, fats)
Add and manage meals with nutritional values
Track food budget and expenses
Automatic calculation of total nutrition and remaining goals
Email notifications for:
Upcoming meals
Daily diet reminders
Budget alerts (optional)
Simple and user-friendly interface

Technologies Used
HTML
CSS
JavaScript
MySQL
GitHub
PHPMailer (for sending emails)
